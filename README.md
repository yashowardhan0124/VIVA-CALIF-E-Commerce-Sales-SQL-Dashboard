# 🛍️ VIVA CALIF — E-Commerce Sales Dashboard

An interactive Excel dashboard built to analyze apparel sales performance for a 
California-based e-commerce brand ("VIVA CALIF"). The report turns raw 
transaction-level data into an executive-ready view of sales trends, customer 
behavior, and delivery performance — fully interactive via slicers, no code required.

## 📌 Overview
Built entirely in Excel using **PivotTables, PivotCharts, Slicers, and a Choropleth 
Map**, this dashboard answers key business questions apparel retailers care about:

- 📈 What are our sales trends over the last 13 weeks?
- 🛒 How do customers prefer to buy — App, Website, Instagram, Target.com, Partner App?
- 👕 Which products are the most popular?
- 🗺️ Where do our customers live (California county-level breakdown)?
- 🔢 How many units do customers typically purchase per order?
- 🚚 How long does it take us to ship orders?
- ⭐ How satisfied are our customers (ratings over time)?

## 🧰 Tech / Tools Used
- Microsoft Excel (PivotTables & PivotCharts)
- Slicers for dynamic filtering (Gender, Order Mode)
- Excel Maps (Geo Chart) for county-level sales distribution
- Calculated fields (Days to Deliver, Weeknum, Gender Value)

## 📂 Dataset
Transaction-level sales data including:
`TX ID`, `Product`, `Quantity`, `Unit Price`, `Amount`, `Order Date`, `Ship Date`, 
`Customer Gender`, `Order Mode`, `Rating`, `State`, `County`

## 🚀 How to Use
1. Download `ecommerce-dashboard.xlsx`
2. Open in Excel (2016+ recommended for full chart/slicer support)
3. Use the **Gender** and **Order Mode** slicers on the left to filter all visuals dynamically
4. Explore the map, trend line, and product bar charts interactively
